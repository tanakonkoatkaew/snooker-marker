# Snooker Marker

กระดานนับแต้มสนุกเกอร์บนเว็บ สำหรับ **15 แดง** (เบรกสูงสุด 147) และ **6 แดง** (เบรกสูงสุด 75) ตามกติกาสากล WPBSA

เป็นไฟล์ HTML ไฟล์เดียว ไม่ต้อง build ไม่มี dependency และไม่มี backend

## ความสามารถ

- สลับโหมด 15 แดง / 6 แดงได้จากหัวหน้าจอ
- เปิดให้กดเฉพาะลูกที่แทงได้ตามกติกา: แดง → สีใดก็ได้ และเมื่อแดงหมดต้องเก็บสีตามลำดับ เหลือง → ดำ
- นับแดงหลายลูกในช็อตเดียวได้
- ฟาวล์ 4–7 แต้ม และไม่ให้เลือกต่ำกว่าขั้นต่ำตามลูกเป้าหมาย
- นับแดงที่ลงหลุมในช็อตฟาวล์ได้
- หลังฟาวล์เลือกได้ว่าฝ่ายตรงข้ามแทงต่อ, ให้คนทำฟาวล์แทงอีกครั้ง หรือ Foul and a Miss (วางลูกคืน)
- ฟรีบอล
- ลูกดำลูกสุดท้าย: แต้มหรือฟาวล์แรกจบเฟรม และถ้าเสมอจะตั้งลูกดำใหม่ (Re-spotted black)
- แสดงแต้มที่เหลือบนโต๊ะและผลต่าง
- แผงวิเคราะห์เฟรม: แต้มขาด จำนวนสนุ๊กที่ต้องการ ประมาณการจำนวนครั้งที่ต้องวางสนุ๊ก และคำแนะนำว่าควรสู้ต่อหรือจบเฟรม
- เมื่อฝ่ายที่ตามอยู่เริ่มมีแต้มขาด จะมีหน้าต่างกลางจอให้เลือกสู้ต่อหรือจบเฟรม
- มุมมองมือถือ: สกอร์ติดด้านบน ส่วนลูกและปุ่มติดด้านล่าง กดได้โดยไม่ต้องเลื่อนหน้า
- นับเฟรมแบบ Best of N ผู้เบรกสลับกันทุกเฟรม และกดยอมแพ้เฟรมได้
- ตารางผลแต่ละเฟรมและรายการเบรกใหญ่
- ย้อนกลับได้ทุกการกระทำ
- บันทึกแมตช์ไว้ในเบราว์เซอร์ (localStorage) ปิดแล้วเปิดใหม่ก็เล่นต่อได้
- คีย์ลัด: `1`–`7` แทงลูกลง · `M` จบเทิร์น · `F` ฟาวล์ · `Z` ย้อนกลับ

## รันในเครื่อง

เปิด `index.html` ในเบราว์เซอร์ได้เลย หรือเปิดผ่านเซิร์ฟเวอร์:

```sh
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000
```

## Deploy

### GitHub Pages (ตั้งไว้แล้ว)

มี workflow ที่ `.github/workflows/pages.yml` ซึ่งจะ deploy ทุกครั้งที่ push เข้า `main`
ก่อนใช้ครั้งแรกให้เปิด Pages ก่อน: **Settings → Pages → Source: GitHub Actions**
หรือรันคำสั่งนี้:

```sh
gh api -X POST repos/{owner}/snooker-marker/pages -f build_type=workflow
```

เว็บจะอยู่ที่ `https://<username>.github.io/snooker-marker/`

### ที่อื่น

เป็น static site ไม่ต้อง build จึงใช้ที่ไหนก็ได้:

- **Cloudflare Pages / Netlify / Vercel:** import repo นี้ ไม่ต้องใส่ build command และตั้ง output directory เป็น `/`
- **เซิร์ฟเวอร์ของตัวเอง:** คัดลอก `index.html` กับ `favicon.svg` ไปไว้ใน web root
